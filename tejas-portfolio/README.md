# Tejas Patil — Premium Sports Data Analyst Portfolio

An editorial portfolio designed for **Tejas Patil**, Sports Data Analyst & Business Analytics professional. Built with **React 19**, **TypeScript**, and **Vite**, featuring smooth Lenis/GSAP scroll choreography, CSS 3D interactive scenes, and verified credentials.

## 🚀 Key Highlights

- **Visual Direction**: Editorial White/Warm-White surface with Deep Red accents (`#ff1f1f`) and high-legibility typography.
- **Scroll Orchestration**: Lenis smooth scroll engine driven by the GSAP ticker with section interpolation.
- **Verified Credentials**: Real credentials from Physics Wallah (PW Skills), Sixladders, Rubicon Skill Development, and School of Machine Learning.
- **Featured Projects**:
  - **CurricuLab** — Student Centric Study Management System (Live on Render)
  - **House Price Prediction** — ML regression workflow (Python, Scikit-learn, Pandas)
  - **Heart Health Analysis** — Biometric and cardiovascular data analytics
  - **Power BI Executive Dashboard** — Business intelligence reporting with DAX
- **Accessibility & UX**: Tested for reduced-motion preferences, keyboard navigation, visible focus indicators, and semantic hierarchy.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Vanilla CSS (Tailored Design System, CSS 3D transforms, CSS Grid)
- **Typography**: Anton, Inter Tight, JetBrains Mono
- **Scroll & Motion**: Lenis, GSAP Ticker

## 💻 Development & Build

Install dependencies:
```bash
npm install
```

Start the local development server:
```bash
npm run dev
```

Type-check and build for production:
```bash
npm run typecheck
npm run build
```

Preview production build:
```bash
npm run preview
```
